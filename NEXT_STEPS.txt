QUICK VERSION:
──────────────────────────────────────────────────────────────

A. Setup Database (3 menit):
   1. https://supabase.com → Sign up/Login
   2. New Project: "kas-ti26a3", Region: Singapore
   3. Copy connection string dari Settings → Database

B. Deploy to Vercel (5 menit):
   1. https://vercel.com → Login with GitHub
   2. Import Project → Select "kas-ti26a3"
   3. Add Environment Variables:
      DATABASE_URL=<dari-supabase>
      NEXTAUTH_URL=https://your-app.vercel.app
      NEXTAUTH_SECRET=<generate: openssl rand -base64 32>
   4. Deploy!

C. Setup Database:
   npm install -g vercel
   vercel login
   vercel link
   vercel env pull .env.production
   DATABASE_URL="..." npx prisma migrate deploy
   DATABASE_URL="..." npx prisma db seed

✅ DONE! App live di Vercel.

═══════════════════════════════════════════════════════════════
  🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

MASALAH: Git remote already exists
SOLUSI:
  git remote remove origin
  git remote add origin https://github.com/YOUR_USERNAME/kas-ti26a3.git
  git push -u origin main

MASALAH: Permission denied (publickey)
SOLUSI:
  Pakai HTTPS instead of SSH:
  git remote set-url origin https://github.com/YOUR_USERNAME/kas-ti26a3.git

MASALAH: File .env ikut ter-push
SOLUSI:
  git rm --cached .env
  git commit -m "Remove .env"
  git push
  ⚠️ Regenerate semua secrets!

MASALAH: Build failed di Vercel
SOLUSI:
  • Check environment variables
  • Lihat logs di Vercel dashboard
  • Biasanya: missing env vars atau TypeScript error
