## ⚠️ PENTING: Keamanan

1. **Ganti password setelah login pertama**
   - Masuk ke Settings > Change Password
   - Gunakan password yang kuat (min 8 karakter, huruf besar/kecil, angka, simbol)

2. **Jangan share credentials**
   - Simpan password di tempat aman (password manager)
   - Jangan kirim via WhatsApp/email/chat yang tidak terenkripsi

3. **Logout setelah selesai**
   - Selalu logout jika menggunakan komputer bersama
   - Jangan centang "Remember me" di komputer publik

## 🔧 Troubleshooting

### Lupa Password
1. Hubungi admin untuk reset password
2. Admin bisa reset via Dashboard > Mahasiswa/Users

### Tidak Bisa Login
1. Cek email/NIM sudah benar
2. Cek password (perhatikan huruf besar/kecil)
3. Pastikan akun sudah aktif
4. Clear browser cache dan coba lagi

### Error 500
1. Refresh halaman
2. Coba browser lain
3. Hubungi admin jika masih error
